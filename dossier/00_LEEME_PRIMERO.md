## Regla de oro (pegar en la pared)

1. **Máximo 2 frentes activos** a la vez. Todo lo demás = *congelado* o *archivo*.
2. **Sin demos → no crear más productos.**
3. **Sin anticipo → no abrir alcance.**
4. No reabrir decisiones ya tomadas (ver §5 de `Marco_Teorico_Indioyori/ops/BITACORA.md`).
5. Producir papers/blog solo **después** de un cobro o un envío comercial esa semana.

## Fórmula del ecosistema (no mezclar piezas)

```
Teoría (papers)
  → Manual de Soberanía Cognitiva
  → MCC          = método de USO
  → MACS         = AUDITORÍA (falla de mandato)
  → IPA          = PROTOCOLO de instrucción
  → ISD          = MÉTRICA (aún sin unificar)
  → TEKTRON      = INFRA Edge / demo viva
```

Secuencia comercial institucional: **MACS → IPA → MCC (formación)**.  
No empaquetar como “MACS/IPA”. No llamar “Auditoría MCC” a MACS.
