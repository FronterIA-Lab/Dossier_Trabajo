## Definición de “terminado” (MVP)

El curso está **terminado para vender** cuando existan:

1. Link de pago en la landing (aunque sea Mercado Pago / Gumroad).  
2. Media de **Módulo 1 y Módulo 2** (video o audio).  
3. El resto de módulos con texto/plantillas ya existentes (los compradores early reciben oleadas).  
4. Correo de entrega automática o proceso manual simple (PDF/ZIP + acceso aula).

**No** esperas a grabar las 13 lecciones para publicar.
